# 合并官方代码操作手册

合并官方代码后，按下面步骤做即可。

## 操作步骤

```sh
# 1. 同步依赖 + 重装 hooks
pnpm install

# 2. 清理过期构建产物
pnpm run clean

# 3. 可选：验证类型检查（较慢属正常，clean 后第一次是全量构建最慢；通过后 push 不会被卡住）
pnpm run typecheck

# 4. 推送（本地与远程分叉时用 force push）
git push --force-with-lease origin my_main
```

## push 失败时的处理

- 如果 push 报 `failed to push some refs`，先跑 `pnpm run typecheck` 看报错。
- 通常是构建产物过期，跑 `pnpm run clean` 后重新 push 即可。
- 想临时跳过钩子直接推：
  ```sh
  git push --force-with-lease --no-verify origin my_main
  ```

## 命令速查

```sh
pnpm install              # 同步依赖 + 重装 hooks
pnpm run clean            # 清理过期构建产物
pnpm run typecheck        # 类型检查
git push --force-with-lease origin my_main   # 安全 force push
git push --force-with-lease --no-verify origin my_main  # 跳过钩子 force push
```
